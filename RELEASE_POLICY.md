# Release qualification and public-scope boundary

**This repository is a public pre-v1 source review surface, not v1.0.** The canonical private programme retains its own releases and evidence. Public review material contains two selected original MIT-licensed skill contracts only.

Hard gates remain: independent security and license provenance; sandboxed real engine and assistive technology results; real GPU/WebGL drawing and context restoration on a qualified host; reproducible browser and source checks; independent blind human UX/visual reviews; a scoped user-authorized reversible project pilot; sanitized first-party distribution; and explicit human release authorization. Unknown gates are HOLD, not implicitly approved.

Third-party agent-skills, GSAP/Motion/Three/R3F engines, React Bits components and other code are **not** bundled. React Bits' Commons Clause restricts component redistribution in bundles. No jury mapping, signing keys, original private research archive, or third-party source shall be committed.
