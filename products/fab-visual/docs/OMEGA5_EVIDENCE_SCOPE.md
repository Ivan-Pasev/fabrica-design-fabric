## Implemented and tested

- 54/54 local Node.js 22.16.0 tests passed; tests include SceneIR, state machine, installer, tamper rejection, upstream SDF/solid projection, independent AABB intersection and ray/box occlusion checks.
- Isometric visual artifact generated by native Anatomy `slabOf` geometry and bounded upstream `A.settle/A.depthOrder`, with an explicit raster `step=2.5` and visible `SAMPLED_NOT_FORMAL` label.
- Thin wires behind a plate produce upstream `overlapsOf` pair count 0 for radii 0.05 and 0.15 at `step=0.25` in a concrete local fixture. The independent center-ray AABB check finds occlusion. Hence `INCONCLUSIVE` is mandatory; absence of sampled overlap is not visibility proof.
- Five-frame synthetic CodexStation policy-state demonstration carries replayable event traces and detects forged authorization, visual release status and invalid transition histories. These are claims about a **synthetic** model only.
- Additive dry-run-first CodexStation installer copied the pinned source subset into a disposable fake host, reproduced hash checks and rendered the synthetic timeline. No real host was modified.
- Static SVG rasterized through CairoSVG and visually inspected. Headless Chromium screenshot attempt was unsuccessful; no browser-driven interaction or screen reader evidence can be claimed.
