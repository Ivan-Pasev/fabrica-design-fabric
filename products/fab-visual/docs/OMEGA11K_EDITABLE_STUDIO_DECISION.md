# FAB.VISUAL Ω11K — Source-Anchored Imports and Reversible Offline Studio

Version v0.5.0-alpha.0 | Product research candidate | RELEASE HOLD.

## Executable new capabilities

The offline Studio now imports FAB.VISUAL-exported XYFlow/React Flow and Cytoscape.js JSON files against a required validated source SceneIR, preserving source ID, model revision, source authority, claim, observables, component identities, statuses, parent hierarchy and typed flow ports. Reconstructed visual scenes can be edited locally: update x/y/w/h, create illustrative source-compatible connections, undo and redo up to 32 bounded snapshots, and export edited SceneIR, SVG, XYFlow or Cytoscape formats. Original source remains unchanged. Graph digest equality is self-reported content correspondence, not proof of an authenticated original publisher.

Use from products/fab-visual:

    node --test tests/*.test.mjs
    node bin/fab-visual.mjs studio fixtures/policy-scene.json dist/fab-visual-editable.html
    node bin/fab-visual.mjs interchange fixtures/policy-scene.json reactflow dist/scene.reactflow.json
    node bin/fab-visual.mjs interchange-import reactflow dist/scene.reactflow.json fixtures/policy-scene.json dist/roundtrip.scene.json
    node bin/fab-visual.mjs interchange fixtures/policy-scene.json cytoscape dist/scene.cytoscape.json
    node bin/fab-visual.mjs interchange-import cytoscape dist/scene.cytoscape.json fixtures/policy-scene.json dist/cytoscape.roundtrip.scene.json

The CLI import emits separate *.import-report.json and *.witness.json alongside the generated validated scene; it cannot overwrite the original scene or input graph. Arbitrary raw unversioned third-party graph files are deliberately not imported. No third-party node editor runtime has been copied, imported or installed; these are first-party JSON graph format projections and a bounded importer.

## Visual fidelity and claim invariants

The original pinned MIT Anatomy isometric renderer remains available on verified unedited ANALOGICAL scenes. After local editing the Studio disables the stale Anatomy view and compare mode until the edited SceneIR is recompiled and checked. Local reference SVG and graph layouts are derived presentations, never independent real-world geometry or physics verification.

Browser exports of changed scenes include updated SceneIR, SVG, XYFlow and Cytoscape JSON; Mermaid/DOT are refused after an edit until regenerated by the Node CLI, avoiding outdated graph contents. Source-model identity, scientific observables, policy approval and release status stay unchanged. RELEASE HOLD and previous Ω11I failure findings persist.

## Adversarial proof obligations and limitations

Node/Studio rejects stale source digest, altered model authority or claims, release-status promotion, changed node authorization/status/ports/parent, missing or duplicate component IDs, unsupported flow types, dangling edges, malformed coordinates, unknown raw graph formats, and oversized files. Finite browser tests do not establish formal model correctness, full external editor ABI compatibility, authentic source publisher identity, actual GPU frame presentation, physical clearance or CodexStation host permission.

No actual host installation, main merge, managed DB upgrade, database status-authority transfer, scientific admission or production release was undertaken. The central database is an ancillary evolution ledger, not the product architecture.
