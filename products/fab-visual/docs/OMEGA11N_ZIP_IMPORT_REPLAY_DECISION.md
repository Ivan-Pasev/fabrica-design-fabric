# FAB.VISUAL Ω11N — Cryptographically Source-Bound Offline ZIP Import and Revision Replay

**Candidate:** v0.8.0-alpha.0 · **Status:** bounded offline capability under test · **RELEASE HOLD**.

## 1. Actual new product functions

The offline standalone FAB.VISUAL Studio adds **Open portable project ZIP** (local file selection), cryptographically source-bound admission, a local revision-card gallery, previous/next preview, side-by-side original-versus-selected-revision visual diff, and **Apply selected revision**. Replayed snapshots remain reversible via existing undo/redo and may be edited further. The original source scene and its claims remain immutable. A failed import leaves the active editor scene unchanged.

Existing Ω11M local project ZIPs can now be opened directly inside the originating standalone Studio. A different template's ZIP is explicitly refused; a portable ZIP is a visual project, not source authority transferable across models.

## 2. Source and archive admission contract

`src/visual/project-import.mjs` independently implements a bounded ZIP STORE parser: exactly six known UTF-8 text members, 0–12 MB aggregate, no external paths, no compression, no encryption, no file comments, data descriptors, binary payloads, optional additional files, or conflicting local versus central directory headers. It checks exact entry bounds, sizes, contiguous local offsets, CRC32, filename parity and central directory termination. This design deliberately supports our exact emitted archive ABI, not arbitrary vendor ZIP writers.

Admission validates source and manifest schemas, `source/original.scene.json` structural equality against the Studio's embedded source, SHA-256 of canonical SceneIR through Web Crypto (failing closed when unavailable), original source digest, fork source model ID/revision/visual slug, HOLD status and unsigned boundaries. Every historical snapshot is tested against the source-bound `visualDiff` contract. All six original ZIP entries must match the exact output obtained by regenerating the original, fork, canonical visual diff, history, manifest and readme from the admitted source and timeline.

An admitted archive yields a **LOCAL_VISUAL_PROJECT**, not an authenticated publisher claim. A self-reported SHA or a valid CRC alone cannot establish publisher identity. Source digest proves content correspondence to the already embedded source SceneIR. A user who substitutes the entire Studio executable is outside the local-source binding trust boundary; this is not remote cryptographic attestation.

## 3. Legitimate use

1. `node bin/fab-visual.mjs gallery dist/gallery`, open a domain Studio from `dist/gallery/index.html`.
2. Move/resize an illustrative part and choose **Download project ZIP**.
3. Reload the *same original* standalone Studio, select its ZIP in **Open portable project ZIP**.
4. Review the SOURCE-BOUND LOCAL PROJECT ACCEPTED message, browse revision cards, preview without changing the active scene, and explicitly apply the selected local revision.
5. Continue editing/undo/redo and export current scene or project.
